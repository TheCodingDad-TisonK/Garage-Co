## 📖 About

Step into your very own first-person car workshop. Cars roll in broken, and it's your job to take them from the customer desk all the way to a satisfied customer walking out the door with their keys.

Start small in a humble lock-up with a single bay. Take jobs from the desk, diagnose the fault, fix it on the car, collect payment, and send them on their way. The lock-up is set to grow into a full dealership over time.

Built on [**Co-Engine**](https://github.com/TheCodingDad-TisonK/Co-Engine), the same custom engine powering the entire Co-Series.

---

## ✨ Features

- **🔧 Hands-On Repairs** - Take jobs at the customer desk and fix faults directly on the vehicle
- **🚗 First-Person Workshop** - Get up close and personal as you work in your garage
- **🏪 From Lock-Up to Dealership** - Start with one bay in a small lock-up, with plans to expand
- **💰 Earn Your Keep** - Complete jobs and take payment at the till
- **🚪 Interactive World** - Open and close the roll door, interact with your workspace
- **🛠️ Build Mode** - Plan and place items as your workshop grows (`F2` / `C`)

---

## 🎮 Controls

| Key | Action |
| :-- | :-- |
| `WASD` | Move |
| `Shift` | Run |
| `Space` | Jump |
| `E` | Take job from customer / Work on car / Take payment / Pull roll door chain |
| `F2` / `C` | Build Mode & Catalog |
| `Esc` | Pause Menu |

## 🕹️ Play

### From Source
```bash
npm install
npm run build
npm start
```

### In Any Browser
```bash
npm run serve
```
Then open the address it prints, or point a static server at the project folder.
